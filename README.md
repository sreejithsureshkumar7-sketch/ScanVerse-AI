# ScanVerse AI

Real-Time Mobile 3D Object Scanner and AR Visualization Platform.

## Features
- Landing page
- Login/Register UI
- Camera scanner demo
- AI object detection demo
- 3D viewer using Three.js
- Gallery page
- Node.js backend API
- MongoDB model structure

## Tech Stack
Frontend: HTML, CSS, JavaScript, Three.js  
Backend: Node.js, Express  
Database: MongoDB

## Run Frontend
Open `frontend/index.html` in browser.

## Run Backend
```bash
cd backend
npm install
npm start
```
Backend runs at:
```text
http://localhost:5000
```
